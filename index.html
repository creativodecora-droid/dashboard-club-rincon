📁 Actualización de reportes y respaldo

Agrega nuevas actividades manualmente o importa archivos CSV/JSON. Los datos agregados se guardan solo en este navegador. Descarga el respaldo JSON para conservarlos o trasladarlos a otro equipo. Importar un respaldo evita duplicados por identificador.

Para trabajos que superen una hora, registra la duración real en minutos (por ejemplo, 90 = 1 h 30 min). Si se ingresan inicio y fin, se calcula automáticamente. No se inventan duraciones para registros históricos.

💬 Incorporar nuevos chats de actividades

Sube exportaciones de WhatsApp en formato .txt. Los reportes nuevos se agregan a la bitácora sin borrar las 311 actividades históricas. Puedes cargar varios archivos y el sistema evita repetir mensajes ya importados.

Sin nuevas importaciones en esta sesión.

Las fotografías no están incluidas en una exportación TXT sin archivos multimedia. Los datos nuevos se guardan en este navegador; descarga la base consolidada para conservarla y trasladarla a otro equipo. Publicar el HTML en GitHub Pages no sincroniza las cargas entre usuarios.
